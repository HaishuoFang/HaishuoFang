### Hi, I'm Haishuo Fang 👋

PhD researcher at [UKP Lab](https://www.informatik.tu-darmstadt.de/ukp/), TU Darmstadt (advisor: Iryna Gurevych), graduating in 2027.
I work on **reliable and verifiable LLM agents**: post-training agents with reinforcement learning, and building the environments, rewards and evaluations that check whether their outputs rest on evidence.

**Selected work**

- **ProReviewer** (under review): a peer-review agent that links every critique to supporting evidence; an 8B open model post-trained with SFT + GRPO outperforms systems built on a 397B model on average. [project](https://ukplab.github.io/arxiv2026-ProReviewer/) · [code](https://github.com/UKPLab/arxiv2026-ProReviewer)
- **Harbor** (NeurIPS 2026, co-author): open-source framework for agent evaluation and RL environments across 80+ benchmarks. I contributed the [FinanceAgent adapter](https://github.com/harbor-framework/harbor/pull/267). [code](https://github.com/harbor-framework/harbor)
- **InferAct** (EMNLP 2025): detects agent actions that conflict with user intent before they execute. [paper](https://aclanthology.org/2025.emnlp-main.12/) · [code](https://github.com/UKPLab/emnlp2025-inferact)
- **DARA** (ACL 2024 Findings): a tool-using agent that decomposes questions into executable knowledge-graph queries. [paper](https://aclanthology.org/2024.findings-acl.203/) · [code](https://github.com/UKPLab/acl2024-DARA)
- **CARE**: AI-assisted reading platform with 2,000+ users; I designed and integrated its LLM-as-a-judge grading pipeline. [code](https://github.com/UKPLab/CARE)
- **SQuARE** (ACL 2023 Demo): platform for question-answering research. [paper](https://aclanthology.org/2023.acl-demo.55/) · [code](https://github.com/UKP-SQuARE/square-core)

**Other contributions**: [arxiv2md](https://github.com/timf34/arxiv2md) (ar5iv fallback, table extraction from arXiv HTML)
