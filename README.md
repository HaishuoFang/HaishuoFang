### Hi, I'm Haishuo Fang 👋

PhD researcher at [UKP Lab](https://www.informatik.tu-darmstadt.de/ukp/), TU Darmstadt (advisor: Iryna Gurevych), graduating in 2027.
I work on **reliable and verifiable LLM agents**: post-training agents with reinforcement learning, and building the environments, rewards and evaluations that check whether their outputs rest on evidence.

**Open-source work**

- **[Harbor](https://github.com/harbor-framework/harbor)**: framework for agent evaluation and RL environments across 80+ benchmarks. I contributed the [FinanceAgent adapter](https://github.com/harbor-framework/harbor/pull/267): 50 financial-research tasks over SEC filings, with an LLM-as-a-judge grader.
- **[CARE](https://github.com/UKPLab/CARE)**: collaborative AI-assisted reading platform with 2,000+ users; I designed and integrated its LLM-as-a-judge grading pipeline.
- **[UKP-SQuARE](https://github.com/UKP-SQuARE/square-core)**: platform for question-answering and multi-agent QA research.
- **[arxiv2md](https://github.com/timf34/arxiv2md)**: added ar5iv fallback and table extraction from arXiv HTML.
